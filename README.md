# MIDS — My Integrated Daily Study

**MIDS** is an academic productivity platform designed to help students organize their academic activities in one place.

Developed by **Kelompok 9 ISCOM**.

## About the Project

MIDS aims to help students manage their daily study routines, academic responsibilities, and learning goals through a simple and organized platform.

## Planned Features

- Academic schedule management
- Assignment and deadline tracking
- Academic calendar
- Study goals and progress tracking
- Reminders for important academic activities
- User accounts and authentication

## Technology Stack

- **Backend:** Laravel 13
- **Language:** PHP
- **Frontend:** HTML, CSS, and JavaScript
- **Database:** To be configured
